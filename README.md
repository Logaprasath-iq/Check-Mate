# CHECKMATE — Elite Chess Academy & Platform

A modern, responsive, full-featured web platform and management system for an elite international chess academy.

## Key Features

- **Responsive Landing & Academy Pages**: In-depth About, Programs, Tournaments, Pricing, Gallery, and Contact pages.
- **Blog System**: Curated chess strategy, openings, psychology, and endgame analyses with individual detail pages and social sharing.
- **Interactive Tournaments & Schedules**: Countdown timer, tournament registration modals, and hybrid digital event listings.
- **Student Portal**: Student dashboard with syllabus progress, scheduled lessons, practice puzzles, and study archives.
- **Admin Management Console**: CRUD dashboards for managing students, tournament registrations, testimonials, orders, and blog posts.
- **Theme Support**: Seamless Dark and Light mode switching with contrast-optimized typography and components.
- **RTL Support**: Full right-to-left layout support for multilingual accessibility.
- **Modern UI/UX**: Built with vanilla HTML5, CSS3, JavaScript, Lucide Icons, and Swiper.js.

## Directory Structure

## Getting Started

1. Clone or download this repository.
2. Open index.html in any modern web browser or serve with Live Server / local HTTP server.
