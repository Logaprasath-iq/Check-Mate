3. Brand Colors & CSS System

Colors are controlled via CSS custom properties in assets/css/style.css. You can customize the championship gold palette or background navy shades simply by modifying: 

:root {
  /* Dark Theme (Default) */
  --bg-primary: #080b12;
  --bg-secondary: #0e1422;
  --gold-primary: #d4af37;
  --gold-light: #f6e29f;
  --gold-dark: #aa820a;
  --gold-gradient: linear-gradient(135deg, #f6e29f 0%, #d4af37 50%, #aa820a 100%);
}

5. Interactive Chess Board & AI Evaluation

Both the 3D perspective board on Home 1 and the live digital board on Home 2 are powered by assets/js/chess-board.js. They feature scalable vector SVG pieces, coordinate labeling, legal square highlights, and move sounds.

To add a playable board to any page, simply insert: 

<div class="chess-board-container interactive-chess-board" id="my-board"></div>

6. Dark / Light Theme & RTL System

The template includes persistent dark/light theme switching and Right-to-Left (RTL) mode out of the box using localStorage. Clicking the language or theme buttons toggles data-theme="dark|light" and dir="ltr|rtl" across public and admin pages.

7. Production Deployment

This is a pure static HTML template. To deploy:

  • Upload the checkmate/ directory directly to any web host (Apache, Nginx, cPanel, Netlify, Vercel, or GitHub Pages).
  • No Node.js build step or runtime server is required.
